# Specifying Connection Properties via Connection Definition Points

## Specifying Connection Properties via Connection Definition Points

[Connection definition points](Glossary_o_verbindungsdefinitionspunkte.md) define the [properties](Glossary_o_eigenschaften.md) of [connections](Glossary_o_verbindungen.md) which run below them.

Precondition:

You have opened a project. You have opened a project page in the graphical editor. You have added a connection definition point.

1. Double-click the connection definition point.
2. Change the values of the existing connection properties or define new ones on the [Connection definition point](devicetaggui_r_vdp.md) tab in the Properties <...> dialog.
3. In the [Display](devicetaggui_r_anzeige.md) tab you can change how properties are displayed in the schematic and in the [Connection graphic](devicetaggui_r_verbindungsgrafik.md) tab you can change the graphical properties of the connection [lines](Glossary_o_leitungen.md).
4. In the [Parts](partselectiongui_r_artikel.md) tab you can assign [parts](Glossary_o_artikel.md) data to the connection.
5. Click [OK].  
     
   ![](../Resources/Pictures/Gui/ALL/arrow.png) The defined properties are only assigned to the connection that intersects the connection definition point in question.
   You can change the properties of more than one connection if you make a multiple selection of connection definition points.

![](../Resources/Pictures/Gui/ALL/info.png)Tip:

In the Connection definition point tab you can automatically determine the next free connection designation in the Connection designation field. For this, use the Determine new designation popup menu item or the [Ctrl] + [N] key combination.

![](../Resources/Pictures/Gui/ALL/note.png)Note:

Connection properties can only be globally edited in the connections navigator (e.g. with regard to several [representation types](Glossary_o_darstellungsarten.md) of a connection). Global editing of connection definition points is not possible - neither for different representation types of a connection nor for several connection definition points on a connection.
