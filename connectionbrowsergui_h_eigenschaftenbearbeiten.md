# Viewing and Editing the Connection Properties

## Viewing and Editing the Connection Properties

1. Select the following commands: Tab Connections > Command group Connections > Navigator.
2. In the Connections - <Project name> dialog mark the desired [connections](Glossary_o_verbindungen.md) and select the Properties popup menu item.
3. In the Properties <...> dialog change the connection [properties](Glossary_o_eigenschaften.md) in the [Connection](devicetaggui_r_verbindung.md) tab and the graphical properties of the connecting [lines](Glossary_o_leitungen.md) in the [Connection graphic](devicetaggui_r_verbindungsgrafik.md) tab.
4. Click [OK].

The properties of a connection can be viewed and edited in the Connections - <Project name> dialog.

![](../Resources/Pictures/Gui/ALL/note.png)Note:

Connections can be assigned additional properties via Connection definition points. Edit these properties at the connection definition point.

![](../Resources/Pictures/Gui/ALL/info.png)Tip:

In the Connection tab you can automatically determine the next free connection designation in the Connection designation field. For this, use the Determine new designation popup menu item or the [Ctrl] + [N] key combination.
