- (constraint) M44 AD-1, AD-3 through AD-11 and AD-13 remain binding: one Canonical Scene, engineering port authority, first-class Function representation binding, relationship truth separate from route paint, full Source Revision CAS, server transactions, fixed writable authority, disposable renderer, deterministic evidence, journal history, and checked performance profile.
- (constraint) M45 PRD is final and requires direct packages/<package-name> children, common PackageItem metadata, closed item kinds, three admission states, provenance lineage, semantic dependencies, explicit FunctionRepresentationBinding, and complete rolling-shutter proof.
- (constraint) Brownfield seams already exist in kernel/package-model, kernel/package-runtime, compiler repository graph/lock materializer, and LSP SourceRevisionService; M45 extends these seams and deletes superseded duplicate contracts instead of adding a parallel package system.
- (decision) Paradigm is a governed package compiler feeding the inherited governed projection pipeline.
- (decision) One PackageItem envelope owns identity, kind, version, digest, provenance, license, lineage, and admission state; Symbol, Element, Part, Macro, Variant, and Placeholder provide kind payloads only.
- (decision) Project package discovery reads immediate directories under packages; directory name must equal manifest packageId; nested registries and runtime reads from reference corpora are forbidden.
- (decision) Package admission is staged parse, normalize, resolve, validate, digest, admit; only PACKAGE_READY items enter binding, snapshot, lock, Source Revision, or scene publication.
- (decision) athena.lock remains compiler-owned canonical resolver output and pins package manifests, exported item digests, required resource digests, dependency edges, and importer/tool identity where conversion produced an item.
- (decision) Symbol owns SVG geometry and keyed anchors; engineering source owns port identity and semantics. Element composes symbols and exposes function slots/public ports. Part owns physical/procurement facts. None may create engineering relationships.
- (decision) FunctionRepresentationBinding is explicit projection binding keyed by Function identity, package item reference, optional variant, typed placeholders, constraints, and package trace; binding changes preserve engineering identity.
- (decision) Import is compile-time tooling: SVG bytes may be copied into governed resources; .elmt and HTML are parsed only to emit native package items/resources. Runtime never parses or loads original import formats.
- (decision) Provenance is an immutable lineage DAG from external source digest through importer operation and PackageItem to binding and scene occurrence; every edge uses stable ids and digests.
- (decision) Macro expands representation composition only through an explicit source transaction; Variant preserves semantic identity; Placeholder performs typed substitution only; none selects Parts or creates engineering relationships.
- (decision) Semantic requires resolve against versioned exported capability/interface contract ids before concrete item binding; exact-byte resource/package dependencies remain explicit lock edges.
- (decision) Golden closure uses examples/m45/rolling-shutter and at least three local packages; proof requires admitted items, real SVG geometry, Parts, composite Element, variants/placeholders, lineage, edit/reopen, canonical SVG, pinned PNG, and fail-closed negatives.
- (version) Inherit verified repository stack: Kotlin 2.4.0, LSP4J 0.23.1, TypeScript 5.9.2, Node.js >=22, Yarn 1.22.22, Theia 1.73.1, Konva 10.3.0, React 18.3.1.
- (direction) Remote registry transport, package publishing/authentication, Engineering Pattern reasoning, universal external format support, 3D, BOM/report, and CAD-scale performance are deferred beyond M45.
- (correction) External catalog formats are reference material only and are removed from M45 system scope. Compiler/runtime admit directly authored Athena package contracts and package-local SVG only.
- (decision) Direct-child package catalog and root athena.yaml dependency intent feed the existing ResolvedPackageGraph; representationPackageRoots and LocalPackageRegistry resolution paths are retired.
- (decision) Repository Lock V2 is replaced by athena-lock-v3; Source Revision derives all package/item/resource detail from the canonical expected-lock model with no second digest ledger.
- (decision) PackageItem phases separate authored PackageItemMetadata from compiler-owned AdmittedPackageItem state/digest/diagnostics; canonical digest projection is versioned.
- (decision) Package provenance ends at PackageItem; compiler usage trace starts at FunctionRepresentationBinding and ends at scene occurrence; read-only provenance view composes them.
- (decision) Package transactions use same-volume staging, durable commit record, recovery, then journal/snapshot/scene publication; cross-memory atomicity is not claimed.
- (decision) Crash recovery persists verified before-image and after-image bytes before PREPARED; deterministic recovery rolls back untouched transactions or rolls forward only from complete verified after-images, otherwise restores before state.
