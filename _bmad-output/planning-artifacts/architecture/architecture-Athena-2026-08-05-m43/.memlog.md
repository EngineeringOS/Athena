- (decision by user) M43 uses separate project source and colocated sheet companion; IDE may virtually group them but compiler authorities remain independent.
- (decision by user) A layout cell is square N x N logical units; N must be a positive multiple of 4; each cell exposes a fixed 4 x 4 micro snap lattice with pitch N/4.
- (decision by user) Authored placement stores occurrence cell and micro anchor plus optional lock; compiler owns exact coordinates, routes, labels, geometry, paint ordering, and Canvas batching.
- (constraint) A1/B3-like references are presentation locations only and never engineering identities; screenshot is QElectroTech visual evidence, not EPLAN implementation authority.
- (decision by user) Sheet grammar uses one scalar cell value only: cell: K where K is a positive multiple of 4; the compiler fixes each macro cell to a 4 x 4 micro lattice, so macro span is 4K x 4K logical units.
- (decision) User approved M43 canvas architecture as the durable arena for future rendering and editing; architecture correctness takes priority over further visual tweaking.
- (decision) AD-2 is amended: in grid: C * R cell: N, N is the count of logical micro subdivisions on each axis of one macro coordinate cell and must be a positive multiple of 4; sheet logical extent is C*N by R*N, micro pitch is one logical unit, and cell: 4 means a 4 x 4 lattice rather than a 16-unit macro pitch.
- (decision) AthenaDiagramScene is the canonical renderer-neutral public shape of Presentation Reality, not another authority or database; it is compiled from Spatial Reality and contains page geometry, stable element and subject IDs, ports, routes, labels, asset references, z-order, source trace, and one revision.
- (decision) The interactive Theia surface has one live scene adapter and one hit-testing owner. Konva is the first adapter; the current independent Canvas route layer plus DOM SVG occurrence layer is retired because it permits transform, revision, and hit-testing drift.
- (version) Konva 10.3.0 is current in npm and local reference/konva commit 914acaf8bc00431ac68e98505d4d8eea1e5ca6bf, MIT, checked 2026-08-06. Athena depends on the pinned npm package and does not copy reference source.
- (decision) Use the imperative Konva package behind an Athena adapter instead of binding Presentation Reality to Konva nodes or react-konva. The existing React 18 Theia widget hosts the adapter; this preserves a small replacement boundary and avoids React scene-node reconciliation as a scale contract.
- (decision) Diagram edits cross the renderer boundary only as typed intent commands with expected revision. M43 MoveOccurrence targets a SheetAnchor and lock intent; ConnectPorts targets stable Port IDs and belongs to engineering-source mutation. Compiler/application services validate, persist the owning Athena source, recompile, and atomically replace the scene.
- (constraint) During drag or connection gesture, adapter may own transient preview, selection, hover, pan, zoom, and tool state only. Preview never becomes source truth; rejection restores the last accepted scene and shows compiler diagnostics.
- (decision) Clean canvas is default: page frame and top numeric/left alphabetic coordinate strips are printable scene facts; interior macro and micro grid lines are absent from normal paint. A future alignment overlay may show subdivisions as viewport-only interaction state and is excluded from export unless explicitly promoted by a future presentation requirement.
- (decision) Package-local SVG, PNG, and icon material enters the scene through digest-addressed AssetRef plus explicit bounds and port anchors. Assets cannot carry engineering facts, arbitrary scripts, external network references, or renderer commands; package compilation validates and sanitizes the admitted asset profile.
- (decision) A deterministic SVG serializer consumes AthenaDiagramScene as the renderer-independent visual oracle and future export base. PNG proof rasterizes an explicit scene revision, scale, background, and font set; SVG bytes may be canonical, while PNG is compared by pinned-environment pixel tolerance rather than promised byte-identical across GPU and OS.
- (decision) Renderer scale strategy is viewport culling, scene-layer partitioning, delegated events, static-layer caching, drag-layer isolation, and zoom-dependent detail. A synthetic 100000-element fixture proves bounded interaction and correctness; measured failure after these controls is the only trigger for a Pixi adapter, never a second scene model.
- (direction) PixiJS 8.19.0, local commit 1d90a20c62433ba68dff78466e06ee372a5a5232, MIT, is ADAPT as a future high-density adapter only if benchmark evidence requires it. No Pixi dependency enters M43.
- (direction) Excalidraw local commit e4ab626739f5f163c5eca56190f615643218b61c, MIT, and tldraw 5.3.0 are ADAPT as interaction-state, selection, snapping, and viewport-culling references; their document stores, shapes, collaboration authority, and UI shells are REJECT for Athena production.
- (direction) Structurizr local commit 9ff16634c3b8574584262ae8545510bbb1d1b4bd, Apache-2.0, is ADAPT for semantic-model versus view separation. Its model, DSL, and rendering contracts are REJECT as Athena runtime dependencies.
- (direction) ELK/elkjs 0.12.0 is ADAPT only as a possible explicit compiler-owned auto-layout service behind Spatial Reality. Live renderer layout, implicit mutation, and M43 dependency are REJECT.
- (constraint) reference/ repositories are read-only evidence. Every borrowed capability records ADOPT, ADAPT, or REJECT disposition, upstream commit/version, license, Athena boundary, tests, and upgrade policy; no production source import or copied framework subtree is allowed.
- (decision) M43 operational envelope remains local Electron/Theia with browser Canvas support, no server, remote collaboration store, WebGPU requirement, or network asset authority. Adapter failure reports a product error; it cannot fall back to legacy renderers.
- (decision) Renderer verification binds scene schema/goldens, deterministic ordering, adapter contract tests, command round trips, selection and port hit tests, nonblank canvas pixel checks, desktop and narrow viewport screenshots, asset safety, and measured scale fixtures. Product closure requires rebuilt frontend and active M43 workspace opened explicitly.
- (decision) AthenaDiagramScene transport is one closed versioned schema with deterministic ordered arrays, integer logical SceneUnit geometry, revision and digest. Kotlin emits it; generated TypeScript plus runtime schema validation consumes it. Frontend does not receive raw Spatial facts and recreate frame, labels, symbols, or hit identities.
- (decision) The adapter computes one uniform viewport transform from scene page bounds using ResizeObserver and devicePixelRatio, fits the page into all available widget space, and keeps logical geometry unchanged. Fixed 1200 x 800 stage sizing and independent layer transforms are retired.
- (decision) Print-clean default means no interior grid, no bottom title table, and no feature-description banner inside the document viewport. Only outer frame, top numeric cells, left alphabetic cells, and compiled engineering content paint unless sheet intent later explicitly adds a document element.
- (decision) Text paint uses compiler-selected style tokens and bundled digest-pinned font assets for stable metrics; adapters cannot substitute system fonts when doing so changes layout. Text input controls may use HTML overlays but cannot become geometry authority.
- (direction) QElectroTech local mirror commit 6d7b38c7a17bc21ee55f34b1319dbc5842c7bae5, GPL-2.0, and EPLAN study evidence are ADAPT for user-familiar page-border and coordinate behavior only. Source code, database shape, proprietary semantics, and compatibility contracts are REJECT.
- (direction) Eclipse GLSP is ADAPT only for protocol and diagram-editor boundary study; its server-side model/operation stack and dependency are REJECT for M43 because Athena already has compiler-owned scene and source command authority.
- (constraint) Before M43 story creation, reconcile PRD and epics with approved spine: cell:N is N by N subdivisions; AthenaDiagramScene is canonical; one Konva interactive adapter replaces split DOM SVG/Canvas hit ownership; clean canvas omits title table and interior grid by default.
- (decision) A governed live document requires exactly one same-basename Sheet Companion. Missing or ambiguous companion produces explicit absence diagnostics and no Presentation Reality; engineering compilation may still serve non-presentation consumers.
- (decision) M41 AD-20, AD-22, AD-26, AD-27, AD-28, and AD-30 remain binding. M41 AD-21 fixed 1200 x 800 proof policy is superseded by M43 logical grid and profile mapping, while its derived/explainable placement principle remains.
- (decision) M43 adds a normative M43-CONTRACT-PACK.md companion. Its scene schema, command schema, profiles, formulas, and conformance vectors are binding; dependent compiler/LSP/adapter stories cannot begin until the contract-pack story passes cross-language tests.
- (decision) AthenaDiagramScene v1 top level is closed and non-null: schemaVersion, sceneId, inputRevision, sceneDigest, page, snapGrid, styles, assets, occurrences, routes, decorations, and traces. Occurrence children own Ports and Labels; Routes are relationship-owned top-level facts; decorations cover frame and coordinate text.
- (decision) Public IDs are opaque typed strings. SceneElementId uses kind plus full lowercase SHA-256 of canonical identity tuple; consumers never parse it. Compiler assigns IDs from stable semantic owners and roles, never geometry, paint, list index, or revision.
- (decision) inputRevision is the canonical compilation-input revision covering source snapshot bytes, package lock/snapshot digests, compiler protocol version, and profile; commands compare against it. sceneDigest is SHA-256 over AD-32 canonical scene JSON with sceneDigest omitted and includes referenced asset/font digests. Assets sort by ID; elements sort by z-index, kind rank, then element ID.
- (decision) Spatial owns page/drawing geometry, occurrence placement/bounds/transforms, placement anchors, Port points, Route points, label anchors/bounds, collision results, and snap grid. Presentation copies/validates geometry, joins resolved styles/assets, derives frame/coordinate paint, hit shapes, and z-order only.
- (decision) A1 lowering uses drawing top-left origin, x right, y down, zero-based row/column indices, Excel-style row labels, and macro origin ((column-1)*N,(rowIndex)*N). micro indices map to offset (x-1,y-1); bottom/right boundary belongs to next cell. Missing micro defaults to (N/2+1,N/2+1). Placement aligns occurrence compiled placementAnchor to that logical point.
- (decision) Snap uses the same versioned formula in Kotlin and TypeScript with canonical vectors. Adapter always selects nearest in-bounds anchor, ties by row, column, microY, microX; outside has no candidate; locked occurrence cannot drag; occupied anchor may preview but compiler overlap validation decides. Preview and committed anchor must match.
- (decision) DiagramEditCommand v1 is a closed generated schema with schemaVersion, commandId, sceneId, expectedInputRevision, source document version/digest preconditions, and sealed MoveOccurrence/ConnectPorts body. Move lock action is PRESERVE, LOCK, or UNLOCK. ConnectPorts carries compiler-advertised relationship definition, roles, Port IDs, and explicit authoring target; UI never infers relationship kind or source file.
- (decision) Runtime DiagramAuthoringService is sole semantic command owner; LSP only transports generated command/result and Theia applies one versioned single-file WorkspaceEdit as one undo unit. Service rejects stale input, compiles an overlay before edit, rechecks source preconditions, returns edit or typed rejection, and never silently rebases. Undo/redo triggers normal recompile.
- (decision) Scene publication envelope states READY, STALE, or UNAVAILABLE with attempted input revision, accepted revision, optional accepted scene/asset bundle, and diagnostics. Invalid text edit may show last valid scene as STALE and non-editable; command validation failure leaves source and READY scene unchanged.
- (decision) Scene trace reuses M42 portable zero-based UTF-16 source references and adds source snapshot digest, role, subject links, primary navigation flag, and ordered related origins. Occurrence/label navigate to semantic declaration, Port to Port declaration, Route to Relationship, frame to Sheet; generated paint retains its owning Sheet/Spatial derivation trace.
- (decision) Compiler securely parses and canonicalizes svg-safe-1 with DTD/entities/external URLs/scripts/events/CSS/animation/filter/foreignObject/text/use/image rejected; admitted shape/group/clip geometry uses inline paint only. Runtime publishes revision-scoped sanitized bytes and WOFF2/PNG bytes in a digest-verified deduplicated asset bundle; adapters never reopen paths or network.
- (decision) Asset limits are versioned profile facts: 2 MiB per SVG source, 4096 x 4096 and 64 MiB decoded per PNG, 4 MiB per WOFF2, and 32 MiB encoded publication bundle. Blob URLs/cache entries are revision-scoped and revoked on replacement or widget disposal.
- (decision) Resolved scene styles use explicit RGBA, integer widths/dashes, caps/joins, font asset ID/size/weight, alignment, and hit geometry. Text anchor/bounds are compiler facts; adapter cannot reposition from local measurement. Deterministic SVG uses fixed attribute/order/escaping profile and exact golden bytes.
- (decision) PNG proof is Electron/Chromium E2E capture, not another scene adapter. It waits for READY scene, admitted assets, document.fonts.ready, and two animation frames; records Electron/Chromium, viewport, CSS DPR, font/asset digests, scene digest, and pixel tolerance.
- (decision) M43 scale gate uses a 100000-paint-element fixture with 5 percent visible, 1600 x 1000 CSS viewport, DPR 1, 60 warm-up and 300 measured frames on recorded hardware. Pass: first paint <=5 s, incremental heap <=512 MiB, pan/zoom/drag p95 <=50 ms, selection p95 <=100 ms, zero hit/trace errors. Failure blocks M43 closure and triggers adapter/culling correction; no claim by evidence-only recording.
- (decision) Exact direct frontend dependencies are ajv 8.20.0 and konva 10.3.0; committed schemas and generated validators/types ship in the Athena Theia frontend extension. No transitive hoisting is accepted.
- (decision) Active raw athena/projectionSession presentation payload, Kotlin/TypeScript duplicate DTOs, split DOM SVG/Canvas widget paint, frontend frame/row-label geometry reconstruction, old CSS selectors, and old M43 proof selectors are removed in the replacement story; no parallel presentation path survives.
- (decision) Semantic source never defines, selects, or draws an entity shape. It owns stable Port identity, direction, flow, and engineering properties. A governed IEC/part symbol SVG owns only visual geometry, visual center, and named visual anchor coordinates/properties. Symbol-anchor metadata may reference an existing Port only for compiler validation/mapping; it cannot create, rename, remove, or alter a Port or its direction, flow, or engineering properties. Representation package selection/mapping stays outside Athena semantic grammar. M43 svg-safe-1 remains a safe generic asset profile until a versioned symbol-asset profile implements the narrow visual metadata whitelist.
- (decision) PresentationAssetCompiler is sole asset/package resolver. It consumes locked package/profile snapshot, validates references only against existing Engineering Port IDs, and emits SceneAsset plus compiler-owned visual ScenePort geometry. It includes package/profile/asset digests in inputRevision. Adapters consume scene and bundle only. M43 svg-safe-1 treats id/title/desc and any anchor-like metadata as inert; Story 2-2 does not parse symbol anchors. A future versioned symbol-asset-v1 profile must define the closed visual center/anchor metadata schema and fail closed on missing, surplus, or mismatched anchors.
