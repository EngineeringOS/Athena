- (constraint) M45 AD-1, AD-5, AD-7, AD-8, AD-12 through AD-17, AD-19, and AD-20 remain binding: one Scene, relationship truth not paint, explicit bindings, source transactions, replaceable renderer, package safety, and no compatibility paths.
- (decision) Paradigm is semantic-first staged compiler: Engineering Reality -> canonical Connection IR -> Connection Projection -> Spatial Route Plan -> Canonical Scene -> renderer.
- (decision) EngineeringDocument gains first-class EngineeringConnection and EngineeringNet collections; generic EngineeringRelationship remains for non-connection meaning and is no longer projected as a route by default.
- (decision) EngineeringConnection is binary; EngineeringNet owns multi-endpoint equivalence. Neither is synthesized from graphic adjacency.
- (decision) ConnectionEndpoint owns Engineering Port reference plus SOURCE/SINK/PASS role; Port direction remains separate device-local fact.
- (decision) ConnectionKind and PhysicalConnectionRequirement are source-owned typed contracts in engineering-model; M46 electrical kinds are conductor, wire, cable core, jumper, busbar, and signal.
- (decision) ConnectionSpecification precedence is project < potential/signal < Net < Connection; same-level contradictions reject compile.
- (decision) New kernel/connection-model module owns renderer-neutral Connection IR, topology operators, canonicalization, and digest protocol. It depends on engineering-model only.
- (decision) ProjectionConnection is replaced by ConnectionProjection referencing Connection IR identity and projection endpoints; arbitrary generic relationships no longer become connection projections.
- (decision) SpatialRoute is replaced by ConnectionRoutePlan carrying typed segments, junctions, crossings, shared segments, interruption anchors, annotation anchors, quality metrics, and source trace.
- (decision) ConnectionRoutePlanner uses deterministic lexicographic cost: validity, obstacle avoidance, ambiguity, crossing count, bend count, route length, stable identity. Existing SpatialRouteCompiler is replaced, not adapted.
- (decision) SceneRoute is replaced by SceneConnection carrying paths, junction/crossing markers, annotations, semantic identity, endpoint identities, stable style refs, and trace.
- (decision) Konva and SVG render SceneConnection only. Paint sizes stay constant in screen space; hit geometry remains invisible.
- (decision) Connect/Reconnect are EngineeringEditOperation; route bend/segment edits are PresentationEditOperation. Both use Source Revision CAS, transaction, journal, recompile, then publish.
- (decision) Connection Navigator reads compiler-owned ConnectionReadModel and emits typed intents; route selection becomes semantic selection without changing style or label modes.
- (decision) M46 uses current pinned Kotlin 2.4.0, Theia 1.73.1, Konva 10.3.0, TypeScript 5.9.2, Node >=22, Yarn 1.22.22, and LSP4J 0.23.1 already verified by M45 brownfield code.
- (decision) No ELK runtime dependency in M46. ELK is research input only; custom deterministic planner remains authoritative to avoid duplicate model/authority.
- (decision) M46 example is a new examples/m46/rolling-shutter project; no M45 example sharing. Evidence stays under implementation-artifacts/m46.
