- (decision by user) M43 primary product outcome is professional live Theia document output; PDF and export remain later.
- (decision by user) M43 uses colocated project.athena and project.sheet.athena; sheet owns presentation intent and authored placement constraints only.
- (decision by user) Grid syntax exposes cell: K only, K positive multiple of 4; every layout cell has implicit 4 x 4 micro snap positions.
- (event) PRD finalized after self-review; FRs, NFRs, metrics, scope, and cell scalar contract are ready for architecture and stories.
- (override) Approved architecture replaces live hybrid DOM SVG plus Canvas ownership with one canonical AthenaDiagramScene and one interactive adapter; SVG remains deterministic renderer-independent oracle/export base, not a second live hit-testing surface.
- (override) cell: N now means N by N subdivisions inside each A1-style macro cell, with N a positive multiple of 4 and micro indices 1..N; cell: 4 yields a 4 x 4 lattice and grid 17 * 16 yields 68 x 64 logical units.
- (decision) Governed live document requires exactly one same-basename Sheet Companion; missing or ambiguous companion produces explicit absence diagnostics and no Presentation Reality, with no default or legacy layout fallback.
- (override) Professional default page is print-clean: outer frame, top numeric and left alphabetic coordinate border, engineering content, no interior grid, no bottom title table, and no instructional banner; alignment grid is a future viewport-only toggle.
- (change) Operational M43 canvas must prove selection, source trace, drag/drop to a Sheet Anchor, lock persistence, atomic recompile, stale-revision rejection, and a typed Port-to-Port connection command that mutates engineering source only after validation.
- (decision) M43 still has no user-facing PDF/export workflow. Deterministic SVG and environment-pinned PNG exist as renderer parity and product proof contracts.
- (change) Large-project readiness is evidence-driven: include a synthetic 100000 scene-element benchmark with recorded load, memory, visible-node count, input latency, and frame-time metrics; do not claim scale beyond measured results.
