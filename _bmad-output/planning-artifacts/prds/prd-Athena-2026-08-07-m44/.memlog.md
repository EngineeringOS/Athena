updated: 2026-08-07T10:14

- (decision) M44 owns asset-first rendering quality, editable canvas operations, and source round-trip; it does not expand into full workspace, AI, macro authoring, reports, or WebGPU.
- (decision) IEC and vendor elements are library dependencies resolved through existing ENGINEERING/REPRESENTATION packages, athena.lock, snapshots, and digests; projects reference package items instead of copying SVG bytes.
- (decision) Device, Function, Part, Symbol, Connection, Route, and Sheet remain separate authorities aligned with the EPLAN study.
- (decision) Library metadata carries center/hotspot, connection-point keys, direction, engineering domain, signal/flow kind, label zones, provenance, and license; semantic source does not store SVG coordinates.
- (decision) AthenaDiagramScene is the only renderer-neutral scene; KonvaCanvas2DBackend is the M44 interactive backend and SVG/PNG consume the same scene and locked bytes.
- (decision) All canvas edits use typed operations with revision checks and atomic validated source patches; no direct scene persistence or frontend engineering logic.
- (decision) Persisted styles live in sheet style companions; session overrides remain transient until explicitly solidified.
- (event) Approved M44 design is stored at _bmad-output/planning-artifacts/m44/design.md and is the primary design input for this PRD.
- (decision) Engineering source owns Port identity and semantic direction/domain/flow; library metadata owns keyed geometry and compatibility only; mismatch blocks publication.
- (decision) Symbol package item is exactly one canonical SVG plus one canonical metadata descriptor with canonical digest, required fields, namespaced extensions, and provenance/license trace.
- (decision) M44 proves one Entity with multiple Function/Symbol occurrences and one cross-domain relationship while keeping electrical-first visual fixture and one renderer.
- (decision) Source Revision is compare-and-set over inputRevision, source/sheet/style/lock/package/compiler/schema/root digests; operations declare writable files and publish atomically with correlation id.
- (decision) Canonical SVG bytes must be exact deterministic; PNG is pinned Electron/Chromium raster evidence with recorded environment and pixel tolerance.
- (decision) M44 delivery order: Must locked package real symbols trace ports cross-domain relation render Move Align rejected edit; Should broader operations style history performance; deferred macros and incomplete transactions.
- (decision) Style Companion discovery is same-basename optional; missing uses defaults; multiple is error; digest participates in Source Revision and scene trace.
- (decision) Structured EPLAN =Function +Location -Device identity and Terminal/Cable/Wire/BOM/report/manufacturing projections deferred; typed identities remain mandatory.
- (event) PRD finalized after blocking decisions resolved: port authority, metadata syntax, source revision, atomic transaction, export determinism, staged scope, and performance profile.
- (decision) Accepted review: M44 is first complete engineering authoring transaction loop, not canvas-only milestone; closure requires golden authoring loop.
- (decision) EditOperation hierarchy added: PresentationEditOperation, RepresentationEditOperation, EngineeringEditOperation; each has fixed authority and writable source boundary.
- (decision) RepresentationBinding and RepresentationInstance added to prevent Function/Symbol coupling and support future multi-view representations.
- (decision) Operation Journal added as accepted source transaction history; Undo/Redo use journal, not mouse events or renderer state.
- (decision) Macro in M44 is representation reuse only; engineering solution reuse belongs to future Pattern authority.
