- (decision) M46 is a connection professionalization milestone: semantic Connection and Net truth first, Connection IR second, deterministic layout/projection third, renderer paint last.
- (decision) Athena source owns Connection, Net, endpoint roles, potential/signal, connection kind, physical requirements, and authored relationships; package SVG never owns these facts.
- (decision) Connection IR is compiler-owned normalized engineering/projection handoff and must preserve topology, endpoints, connection class, physical requirements, provenance, validation, and stable identity.
- (decision) Connection projection owns junction, crossing, bridge/interruption, route segments, label anchors, and style references; Canonical Scene remains renderer-neutral.
- (decision) M46 adopts EPLAN lessons for connection types, property inheritance, unplaced connections, target order, connection definition overlays, and navigator inspection without copying EPLAN graphic-first authority.
- (decision) Golden rendering target is draft/screenshort/equipement_d'un_volet_roulant.png under AGENTS visual rules: thin orthogonal linework, tiny points, compact labels, clean white sheet, edge rulers, no default grid or bottom table.
- (decision) M46 uses existing Kotlin/Theia/Konva stack and M45 package-backed rolling-shutter project; no new renderer and no backward compatibility path.
- (decision) Connection editing uses typed source transactions and full Source Revision; route drag is presentation intent, reconnect is engineering intent, both recompile before publish.
- (decision) M46 closure requires sequential tests, rebuilt Theia/LSP, workspace-root READY proof, deterministic SVG/PNG, desktop/narrow screenshots, hygiene audits, and retrospective.
