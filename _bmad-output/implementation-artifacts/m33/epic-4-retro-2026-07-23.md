# Epic 4 Retrospective - Professional Sheet Composition

## Epic Review

Epic 4 completed all three stories. Athena now has renderer-neutral facts for sheet/frame/title/
zones, rails/lanes/terminal strips/label bands/route channels, and typed reference/continuation
placement. Bounds derive from Graphic Primitive content and explicit policy; projection,
representation, structure-intent, policy, and derived-geometry authorities remain distinct.

Final verification passed sequentially: drawing-composition, projection, and representation module
tests; all 151 Gradle tasks; all 204 frontend tests; encoding and diff checks.

## What Worked

- Story 4.1 established one generic composition module instead of expanding M30's broad electrical
  membership proof.
- Explicit structure intents prevented device-name/type heuristics and generic graph spacing from
  becoming layout authority.
- Typed `ProjectionCrossReference` links and package anatomy ids replaced fixture-name or DOM
  inference for references.
- Every invalid path fails closed with no partial plan, proof, or transport payload.
- Every story used RED/GREEN, adversarial review, AC-to-evidence mapping, and polish/purge ledgering.

## Challenges

- Story 4.1 initially conflated projection metadata authority with derived bounds authority.
- Tiny finite dimensions and extreme padding exposed derived underflow/overflow cases.
- Story 4.2 initially accepted duplicate memberships and preserved caller-dependent anchor order.
- Story 4.3 exposed a Gradle API boundary: typed projection references publicly use engineering
  identity, requiring an explicit engineering-model dependency.
- Multi-link and same-sheet references required unique target ids and both SOURCE/TARGET placement
  completeness; a simple cross-sheet sample did not expose those cases.

## Lessons

1. Metadata, policy, upstream bounds, and derived geometry need separate authority fields.
2. Professional composition must consume explicit memberships and anatomy ids; name/type/DOM
   classification is not an acceptable fallback.
3. Validate derived geometry after arithmetic, including underflow and overflow.
4. Reference facts need link-level identity, not only cross-reference identity.
5. Module proof is not live product proof. Workbench migration and Electron evidence remain gated.

## Previous Follow-Through

not remove the active legacy renderer. Full product smoke and live Graph View migration remain open
exactly as recorded in the cleanup ledger.
