### What Worked

1. Contract-first delivery kept Kotlin, LSP, TypeScript, Konva, SVG, and proof on one scene/publication
   contract.
2. Pre-1.0 deletion policy removed raw Projection/Spatial presentation transport and split SVG/Canvas
   authority instead of preserving compatibility shims.
3. The colocated Sheet Companion kept human layout intent separate from engineering meaning:
   `grid: 17 * 16 cell: 4` and `"Supply" at A2` remain concise and inspectable.
4. Deterministic spatial indexing corrected the initial scale regression without adding a renderer or
   second scene model.
5. Trusted Electron input and rendered-pixel probing proved real Konva hit testing rather than a
   synthetic DOM shortcut.

### Challenges And Lessons

1. The center editor initially lost height to automatically ranked bottom panels. Product layout
   ownership must be tested at the workbench level, not inferred from widget CSS.
2. Konva uses multiple canvas layers. Proof that inspects only the first canvas can report a blank
   document or miss the actual hit surface.
3. Selection can succeed before the source editor exists. Product proof must wait for trace UI
   readiness, not only selected DOM state.
4. A frontend rebuild is part of runtime verification. Stale Theia bundles create false debugging
   signals and must be eliminated before changing product assertions.
5. Scale claims need measured culling and identity evidence. The first p95 failure led to a bounded
   `SceneSpatialIndex` correction rather than a budget change or renderer swap.
