# Predefining Connection Properties

## Predefining Connection Properties

[Connections](Glossary_o_verbindungen.md) are given [properties](Glossary_o_eigenschaften.md) from the defaults in the project and the properties of the potential. All other properties are specified in the [connection definition points](Glossary_o_verbindungsdefinitionspunkte.md).

You can specify certain properties for connections in the project [settings](Glossary_o_einstellungen.md) that are then assigned to every connection generated.

The properties specified in the project are inherited by the potential. The [potentials](Glossary_o_potenziale.md) then pass on their properties to the [signals](Glossary_o_signale.md) and then the connections. You can manually change the data on the individual [levels](Glossary_o_etagen.md) and define additional properties.

1. Select the following commands: File > Settings > Projects > "Project name" > Connections > Properties.
2. Select the desired tab, e.g. [Electrical engineering](connectionsettingsgui_r_projekteinstellungenelektrotechnik.md), [Hydraulics](connectionsettingsgui_r_projekteinstellungenhydraulik.md), or [Process engineering](connectionsettingsgui_r_projekteinstellungenhydraulik.md).
3. In the individual fields specify the default values for the connection properties.
4. Confirm your entries.  
     
   ![](../Resources/Pictures/Gui/ALL/arrow.png) The default values are saved. When generating a connection it is automatically assigned the corresponding default values.
